# OBD11 & OBD11 VAG Bypass

Helps bypass the **Update Required** screen in OBDeleven and OBDeleven VAG by making each app report a newer version and build number.

- Separate enable switches and version settings for each app.
- Reset buttons, Respring, and a GitHub link in Settings.
- For rootless iOS 16 jailbreaks, including Dopamine.

Install the `.deb` from [Releases](https://github.com/551UK/OBDeleven-Patch-iOS16/releases/latest) using Sileo. Open **Settings → OBD11 & OBD11 VAG Bypass**, choose your settings, then fully close and reopen the app.

Turning an app's switch off, or entering its real version, disables its spoofing. If a newer version is required later, change that app's Version field.

Targets OBDeleven 1.11.0 and OBDeleven VAG 1.9.73. VAG needs confirmation on a device; server compatibility is not guaranteed.
