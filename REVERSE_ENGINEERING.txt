4. ForceUpdateViewController presentation fallback
--------------------------------------------------

The state-2 branch constructs ForceUpdateViewController and calls Objective-C
presentation with the same ABI as:

  -presentViewController:animated:completion:

v1.0.2 hooks UIViewController's presentation method and UINavigationController's
push method. A controller whose class hierarchy contains ForceUpdateViewController
is rejected before UIKit can display it.

All binary writes verify the original four bytes before patching. The tweak also
logs when v1.0.2 loads and when a ForceUpdate controller presentation is blocked.
